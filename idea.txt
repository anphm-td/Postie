cấu trúc cũ 
electron/              → Main process (Node.js, có quyền truy cập DB/hệ thống)
  main.ts                 - Khởi tạo cửa sổ, vòng đời app
  preload.ts              - contextBridge: API "an toàn" expose cho renderer
  ipc.ts                  - Toàn bộ handler IPC (renderer ↔ main)
  db/connection.ts        - Kết nối SQLite, resolve path, PRAGMA
  db/repositories/        - 1 module/domain: products, orders, customers, 
                            users, shifts, payment-methods

src/renderer/           → Giao diện React (KHÔNG có quyền truy cập Node/DB trực tiếp)
  routes/                 - Register (bán hàng), Products, Reports, 
                            Login, FirstRunSetup, ShiftOpen
  components/pos/         - Component nghiệp vụ POS
  components/ui/          - Radix UI + Tailwind
  hooks/                   - useCart, useShiftGuard, useSetupGuard
  context/AuthContext.tsx  - Quản lý đăng nhập

src/shared/             → Type dùng chung giữa main và renderer
db/schema.sql            → Schema SQLite (nguồn sự thật duy nhất)
