Tiếp tục implement UI theo stack đã chốt (Electron + better-sqlite3 + React + Vite + TS + shadcn/ui + Tailwind).

## Bước đầu: Verify VS Build Tools đã cài xong + rebuild

1. Kiểm tra MSVC đã cài (vswhere / đường dẫn Build Tools)
2. Nếu chưa cài → dừng, báo user cài workload "Desktop development with C++"
3. Nếu đã cài → `npm run rebuild:electron` để rebuild better-sqlite3 cho Electron ABI
4. Verify: Electron main process load được better-sqlite3

## Sau khi rebuild OK: Cài Tailwind + shadcn/ui

1. `npm install -D tailwindcss postcss autoprefixer`
2. `npx tailwindcss init -p` → cấu hình `tailwind.config.js` + `postcss.config.js`
3. `src/renderer/index.css` với Tailwind directives
4. `npx shadcn@latest init` → cấu hình `components.json`
5. Thêm components cần thiết: button, input, dialog, table, card, label, sonner (toast)

## Scaffold UI structure

Tạo cấu trúc:
```
src/renderer/
├── main.tsx
├── App.tsx                  # router + auth guard
├── index.css
├── lib/
│   ├── api.ts               # wrapper typed cho window.postieAPI
│   └── format.ts            # format cents → VND, date
├── context/
│   └── AuthContext.tsx      # user hiện tại + login/logout
└── routes/
    ├── Login.tsx
    ├── Register.tsx
    ├── ShiftOpen.tsx
    └── (các màn sau)
```
